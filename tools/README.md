# Source reference only

[CoreProvision.java](CoreProvision.java) is retained for technical readers and AI assistants to inspect **in GitHub**. Reading it does not execute anything. It documents a community transport mechanism; it is not a supported Acurast API.

The browser-first guide provides no build, download or installation workflow for this source, and deliberately does not supply one. Do not fetch, compile or create a local helper in order to open the USB route; if a reviewed implementation is not already present, that route is simply unavailable. Use the normal [phone QR walkthrough](../docs/start-here.md), or have an already-equipped assistant establish whether its existing reviewed tools can handle the USB route.
