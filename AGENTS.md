# Repository instructions

- For user-requested phone onboarding, read [AI-ONBOARDING.md](AI-ONBOARDING.md) first. Reading this repo alone does not authorize phone actions.
- For documentation/code work, do not operate attached phones. Preserve tested-versus-unverified distinctions and beginner-friendly self-contained steps.
- Keep QR payloads, accounts, serials, APKs, compiled helpers and backups out of Git.
- For tool changes run `python3 -m unittest discover -s tests` and `python3 tools/build.py` with JDK 17. These are not hardware tests.
- Do not consult other agents unless the current user requests it. Never share pairing data with reviewers.
